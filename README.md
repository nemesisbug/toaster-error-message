A make.fun bounty entry: one line, the funniest error message a kitchen
toaster would show its owner.

## The entry

> E04: TOASTING CANCELLED. THE BREAD ASKED ME NOT TO.

51 characters. Deadpan, apologetic, quietly dramatic — and the surprise
comes from somewhere the obvious toaster puns never go: the bread itself
objects. One clear voice, one read, no setup.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_PATH`).
